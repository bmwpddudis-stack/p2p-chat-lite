# P2P Chat Lite

Минималистичный децентрализованный веб‑чат 1‑на‑1 без бэкенда. Работает прямо в браузере через WebRTC и PeerJS. Всё, что нужно, — открыть ссылку и передать собеседнику свой PeerID (или использовать ссылку с параметром `?room=ID`).

## Особенности

- **Без сервера**: нет бэкенда и баз данных — только HTML/JS и WebRTC.
- **P2P‑соединение**: сообщения идут напрямую между браузерами.
- **Постоянная ссылка для приглашения**: формат `?room=PARTNER_ID` позволяет сразу подключиться к собеседнику.
- **Только текст (MVP)**: минимум кода для быстрого старта.
- **Развёртывание на GitHub Pages**: один файл `index.html`, никаких сборщиков.

## Как запустить

1. Клонируй репозиторий.
2. Загрузи `index.html` в репозиторий на GitHub.
3. Включи GitHub Pages (ветка `main`, папка `/`).
4. Открой ссылку на сайте.
5. Скопируй свой PeerID и передай собеседнику (или сформируй ссылку вида `?room=ID`).
6. Вставь ID собеседника и нажми «Подключиться».

## Технические детали

- **Стек**: HTML5, JavaScript, WebRTC, PeerJS (через CDN).
- **Сигналинг**: PeerJS публичный сигнальный сервер (не твой бэкенд).
- **Передача данных**: RTCDataChannel.
- **Хранение истории**: отсутствует (данные только в памяти браузера).

## Ограничения

- Нет истории сообщений после перезагрузки страницы.
- Прямое P2P‑соединение зависит от NAT/файрволов; PeerJS автоматически использует TURN при необходимости.
- Групповые чаты и медиафайлы не поддерживаются в этой версии.
