# p2p-chat-lite
P2P Chat Lite — децентрализованный чат 1‑на‑1 в браузере без бэкенда. Работает на WebRTC и PeerJS: сообщения идут напрямую. Один HTML‑файл — легко развернуть на GitHub Pages. Ссылка с `?room=ID` даёт мгновенное подключение. Сейчас — только текст, история не сохраняется. В планах — медиа, шифрование, группы.
